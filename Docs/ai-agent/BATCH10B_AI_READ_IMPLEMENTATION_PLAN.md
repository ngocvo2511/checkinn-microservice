## Test strategy and dependency order

10B.1→2→3 policy tests do not need provider or hosted DB; provider key không cần để thiết kế adapters. 10B.6 extraction/runner có thể bắt đầu sau10B.3 trước UI để làm gate cho10B.4. 10B.5 cần stable response schema sau10B.4. Chỉ tới10B.7 mới start stack đã kiểm target. Không default bật integration flags `CHECKINN_*` hay context DB tests.

Commands dự kiến (chưa chạy trong10A): scoped Maven module tests sau khi module tồn tại; Hotel `-Dtest=AgentReadContractTest,AvailabilityReadValidationTest,HotelOfferCriteriaLimitsTest`; Gateway `GatewayObservabilityContractTest,GatewayErrorHandlerMappingTest`; frontend `npx tsc --noEmit --incremental false`, scoped Node tests và relevant Playwright configurations đọc prerequisites trước. `npm ci` chỉ khi cần dependency installation. Existing broad suite counts phải chạy lại nếu dùng làm acceptance; không copy1084/222 từ9H.

Docs-only10A không cần build/test app. Evaluation lẫn kiểm tài liệu không chứng minh Agent hoạt động. Không chạy production provider test hoặc paid lifecycle trong READ MVP vì vượt scope.

## Acceptance gates và safe rollout

G1 dependency compatibility/no secret→G2 adapters/policy100%→G3 conversation/model safety + quantitative evaluation→G4 frontend type/build/UI→G5 local canonical READ trace smoke→G6 human review pilot. Mọi hard security/correctness failure chặn rollout dù overall pass≥95%. Không kích hoạt Agent khi chưa có limiter và finite spend cap. Feature flag mặc định OFF; health chỉ phục vụ monitoring approved ingress; examine discovery-locator aliases to prevent bypassing feature gate/admission. Không thay security service gốc để làm smoke xanh.

Rollback là disable UI/route/Agent flag/process, không thay Hotel/Booking data. Existing booking/payment/refund workflows không bị Agent thao tác. Nếu cần thay schema, proto/event, authorization public/private, model data retention hoặc thêm WRITE/Place, dừng phần đó để mở scope review mới, không “nhân tiện” trong10B.
